# 홈페이지 리뉴얼 — 확인 요청 사항

2026-08-16 · 비트웨이브(㈜지오테스솔루션) 홈페이지 리뉴얼 건

레이아웃과 뼈대는 만들어 두었습니다. 아래 내용이 확정되면 문구에 그대로 반영합니다.
★ 표시는 **이 답이 없으면 해당 페이지를 못 만드는 것**입니다.

---

## 1. 요금 · 무상 지원 범위 ★

현재 홈페이지에 "CTI 솔루션과 연계된 Application 무상 지원"이라고 적혀 있습니다.
이게 경쟁사 대비 가장 강한 무기라 전면에 세우려고 하는데, 조건이 정확해야 합니다.

1. CRM·녹취·통계 프로그램은 **시스템 구축비에 포함**인가요, 아니면 별도 구매 항목인가요?
2. 유지보수비는 **월정액**인가요 **연 단위**인가요? 산정 기준은 무엇인가요? (상담원 수 / 회선 수 / 시스템 규모)
3. 상담원이 늘어나면 **프로그램 비용이 추가**되나요? (좌석당 과금이 있는지)
4. 홈페이지에 **금액을 공개**해도 되나요? 아니면 "상담 후 견적"으로만 갈까요?
   - 참고: 경쟁사 tryvox는 월 29,000~299,000원을 공개하고, 아톡비즈·TWC는 제안서로만 안내합니다.
5. **구축형(장비 구매)** 과 **임대형(월 이용료)** 둘 다 가능한가요? 한쪽만인가요?

## 2. AI 기능 — ✅ 답변 완료

6~10. **전부 판매 중.** 없는 기능도 바로 개발 가능 → 홈과 솔루션 페이지에 전부 기재했습니다.
   - AI 통화요약(STT), AI 응대, 보이는 ARS, 상담원 인계, 문의 유형 분석
   - 기존 고객사 추가 구축 없이 적용 → 상단 배너 문구 유지

11. AI 서버 위치 — **아직 답 없음.** 급하진 않지만 공공·금융 제안 때 반드시 나옵니다.
    - AI 처리 서버가 국내인지 해외인지만 알려주시면 됩니다.

## 3. 실적 · 고객사

12. ~~고객사 수~~ → **50개 기업으로 확정.** 전 페이지 반영 완료.
13. ~~로고 이미지 원본~~ → **원본 없음.**
    - 고객사 로고는 **쓰지 않기로 합니다.** 실제 존재하는 회사의 로고를 저희가 새로 만들어
      붙이는 것은 상표 문제가 되고, 고객사가 노출을 꺼린다는 점과도 어긋납니다.
    - 대신 아래 14번 방식으로 신뢰 섹션을 구성합니다.
14. ~~업종+규모 표기~~ → **가능 확인.** 로고 없이 이 방식으로 갑니다.
    - **필요한 것: 실제 구축 사례 4~6건**
      각 건마다 ①업종 ②상담 석수 ③도입 구성(예: IPCC+CRM+녹취) ④해결한 문제 한 줄
    - 사명이 없어도 이 네 가지만 있으면 신뢰가 생깁니다. 지금은 예시로 채워둔 상태라
      실제 내용으로 교체해야 합니다.
15. 지금까지 구축한 것 중 **가장 큰 규모는 몇 석**인가요?
    - 현 사이트 하드웨어 표에 "101~200명"이 마지막 구간이라, 200석이 상한처럼 읽힙니다. 실제 상한이 맞는지 확인 필요합니다.

## 4. 인증 · 보안

16. **ISMS-P**나 **ISO 27001** 인증을 보유하고 계신가요? 준비 중인 것이 있나요?
    - 아톡비즈는 ISMS-P, TWC는 ISO 27001을 전면에 내세우고 있습니다. 없으면 다른 방식으로 써야 합니다.
17. ~~녹취 보관 위치~~ → **기본 AWS 클라우드, 요청 시 고객사 서버.** 반영 완료.
    - 선택할 수 있다는 점 자체가 강점이라 녹취 페이지에 기능으로 넣었습니다.
      규정상 외부 보관이 안 되는 공공·금융에서 이게 결정적일 때가 있습니다.
18. **조달청 나라장터** 등록이 되어 있나요? (공공 영업 페이지에 필요합니다)

## 5. 브랜드 · 도메인

19. ~~대표 도메인~~ → **bitwave.kr로 확정.** 나머지는 아래처럼 자동 연결(301)합니다.

    | 기존 주소 | 처리 |
    |---|---|
    | `ziotes.com` | bitwave.kr로 영구 이전(301) |
    | `zencrm.ziotes.com` | 로그인 페이지는 그대로 두고, 홍보성 접근만 bitwave.kr로 |
    | `070crm.com` | bitwave.kr로 영구 이전(301) |
    | `bitwave.kr` | **대표 주소** |

    → 필요한 것: 위 도메인 3개의 **DNS 관리 권한**(가비아·후이즈 등 등록기관 계정).
      301로 넘기면 기존 주소에 쌓인 검색 점수가 bitwave.kr로 합쳐집니다.
      단순히 새 주소만 알리고 옛 주소를 방치하면 그 점수는 버려집니다.
20. 홈페이지 앞면에 세울 이름은 **비트웨이브**인가요, **지오테스솔루션**인가요?
21. ~~온라인 마케팅 프로그램 개발·대행~~ → **지금도 진행 중인 사업으로 확인.**
    - 콜센터만 파는 회사가 아니라 **"고객을 데려오는 것부터 응대까지"** 로 범위를 넓힐 수 있습니다.
      전화 시스템만 찾던 곳이 마케팅까지 맡기는 경우가 생깁니다.
    - 별도 페이지로 만들지, 회사소개 안에 한 줄로 둘지만 정해주시면 됩니다.
22. **전국콜비즈(대표번호)** 와 역할을 어떻게 나눌까요?
    - 대표번호 개통 문의는 콜비즈로 넘기고, 비트웨이브는 콜센터·CRM·AI로 가려 합니다.
      같은 키워드를 두 사이트가 동시에 노리면 서로 순위를 깎아먹습니다.

## 7. 참고 — 지금 사이트에서 급히 고쳐야 하는 것

리뉴얼 전이라도 아래는 지금 바로 고치는 것이 좋습니다. 서버 접근 정보를 주시면 처리하겠습니다.

- **고객사 수 충돌** → 한 페이지는 "50개 고객사", 다른 페이지는 "40여 업체"로 서로 다릅니다.
- **오탈자** → "컨텍센터"는 **컨택센터**, "메뉴얼"은 **매뉴얼**이 맞습니다.
