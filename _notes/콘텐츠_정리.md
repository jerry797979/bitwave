### 3-2. 경쟁사 논리 허점 = 우리 공격 포인트

**tryvox의 허점 — AI는 있는데 회선이 없다**
- 자기 페이지에서 "상담사 인계", "기존 번호·콜 인프라에 연결", "SIP 연동"을 계속 말함
  → **AI 에이전트만으로는 콜센터가 안 굴러가고, 결국 교환기·번호·녹취 인프라가 필요하다는 자백**
- 요금도 AI 180원/분 + 발신 20원/건 + 통신료 별도 + 번호료 별도 → **총비용이 안 보임**
- 우리 반격: "AI는 통화의 한 층일 뿐입니다. 회선·교환기·녹취·CRM을 남의 것으로 쓰면
  장애가 났을 때 책임질 사람이 사라집니다." + **총비용 비교표**로 정면 대응

**atalk의 허점 — 기능은 많은데 다 임대(서비스형)**
- 구축비 0원이지만 회선·기능마다 월 과금이 누적, 3년 총액은 오히려 커짐
- 커스터마이징은 "지원"이라고만 하고 소스 수정 범위는 불명
- 우리 반격: **자체 개발 = 소스 레벨 커스터마이징 + 구축형/임대형 선택 가능**,
  3년 총소유비용(TCO) 비교표

**thewc의 허점 — 숫자가 서로 안 맞는다**
- "운영비 최대 50% 절감 개런티"인데 스스로 "AI 해결률 20%, 상담시간 30% 단축"이라고 씀
  → 20% + 30%로 50%가 나오려면 사람(BPO) 축소가 전제. 즉 **절감의 실체는 아웃소싱 인건비**
- 우리 반격: 절감 근거를 **항목별로 쪼개서 제시**(회선료 / 시스템 임대료 / 유지보수 / 상담시간),
  "개런티" 같은 검증 불가 단어 대신 **계산식 공개**

**3사 공통 허점 — 통신사업자가 아니다**
- vox = SaaS, atalk = 재판매 성격, thewc = 솔루션+BPO
- 비트웨이브만 **VoIP 사업자 + 자체 IP-PBX 개발사 + 애플리케이션 개발사**를 동시에 가짐
- → 리뉴얼 전체를 관통할 단 하나의 메시지:

> **"전화선부터 AI까지, 한 회사가 다 만듭니다."**
> 중간 마진이 없고, 소스를 직접 고치고, 장애가 나도 전화 걸 곳이 한 곳입니다.

이건 기존 "국내 유일 Solution 기반 VoIP Service Provider"를 2026년 언어로 번역한 것.

### 3-3. 3사에 있고 우리도 되는데 사이트에 안 쓴 것 (즉시 추가 대상)
문자·알림톡 발송 / 080 수신거부 / 대표번호 그룹 / 패턴 발신 / 웹팩스 / 보이는 ARS /
레터링(발신 브랜드 표시) / 영상상담 / 채팅·SNS 통합상담 / AI 통화요약(STT) /

## 6. 5만 페이지 프로그래매틱 설계 (동적 렌더링)

전국콜비즈와 동일 방식: `functions/local/[[path]].js` + `engine.mjs`로 런타임 생성, 사이트맵만 정적 배포.

**⚠ 카니발라이제이션 주의**
전국콜비즈가 이미 `지역 × 대표번호 개통`을 점유 중.
비트웨이브는 **대표번호 개통 키워드를 피하고** 콜센터·CRM·AI·솔루션 축으로 간다.
대표번호 신청 트래픽은 콜비즈로 링크. (같은 회사끼리 순위 뺏기 금지)

**축 설계**
| 축 | 항목 수 | 예시 |
|---|---|---|
| A. 지역 | 시군구 250 / 읍면동 약 3,600 | 강남구, 정자동 |
| B. 업종 | 33 | 병원, 쇼핑몰, 법무법인, 제조업 |
| C. 서비스 | 12 | 콜센터 구축, CRM, ARS, 녹취, 채팅상담, AI통화요약… |

**조합안 (총 약 5.1만)**
- 지역(시군구 250) × 업종(33) = **8,250** — "강남구 병원 콜센터 구축"
- 지역(읍면동 3,600) × 서비스(12) = **43,200** — "정자동 고객관리 프로그램"
- 업종(33) × 서비스(12) = **396** — 허브 페이지
- 정보성 원고 = 100~200 (수동/AI 생성, 주 2~3회 발행)
- **합계 약 51,900**

**품질 방어 (얇은 페이지 = 색인 제외 위험)**
- 페이지당 최소 900자, 지역 고유 정보(관할 국번·인접 지역·해당 지역 업종 밀도)를 실제로 다르게
- 문단 3개 이상은 조합별로 실제 분기 (템플릿 치환만 하면 안 됨)
- 내부링크: 인접 읍면동 6 + 같은 업종 4 + 서비스 허브 1
- 사이트맵 분할(5만 개 → 5만/45,000 단위로 나눠 제출)
